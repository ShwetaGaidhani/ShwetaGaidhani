### 📌 Featured Projects

#### 🧠 SYNAPSE — AIOps Anomaly Detection Platform
An 8-stage AIOps pipeline (telemetry simulation → anomaly detection → causal root-cause analysis → remediation → continual learning), powered by trained PyTorch models — a graph-convolutional VAE and a GRU-based temporal graph encoder — with a documented heuristic-vs-trained-model tradeoff.
**Tech:** Python, PyTorch, Graph Neural Networks
**Repo:** _add link once pushed_

#### 🌱 EcoTrack — Sustainability Habit Tracker (Android)
Android app for tracking eco-friendly habits, built with a real MVVM architecture and Firebase backend.
**Tech:** Java, Android Studio, Firebase
**Repo:** [EcoTrack](https://github.com/ShwetaGaidhani/EcoTrack)

#### 💬 Sentiment Analysis Tool
Command-line sentiment classifier using TF-IDF with Logistic Regression / Naive Bayes, with a full text-preprocessing pipeline.
**Tech:** Python, scikit-learn
**Repo:** [Sentiment-Analysis-Tool](https://github.com/ShwetaGaidhani/Sentiment-Analysis-Tool)

#### 📷 Face Detection & Recognition
Real-time face detection and recognition system using a live webcam feed.
**Tech:** Python, OpenCV
**Repo:** [Face-Detection-Recognition](https://github.com/ShwetaGaidhani/Face-Detection-Recognition)
